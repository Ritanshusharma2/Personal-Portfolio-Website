  # 💼 Personal Portfolio Website

A modern and responsive **Personal Portfolio Website** built using **HTML, CSS, and JavaScript**. The website provides a professional platform to showcase **skills, projects, education, certifications, achievements, and contact information**. It features a clean and responsive design, smooth navigation, and interactive elements, making it suitable for students, developers, and aspiring software engineers.

## 🚀 Features

* 👨‍💻 Professional Introduction
* 🛠️ Skills & Technologies Section
* 📂 Projects Showcase
* 🎓 Education Section
* 🏆 Certifications & Achievements
* 📄 Resume Download
* 📬 Contact Section
* 🔗 Social Media & GitHub Links
* 🌙 Dark / Light Mode
* 📱 Fully Responsive Design
* ✨ Smooth Scrolling & Animations
* 🚀 Lightweight and Beginner-Friendly

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
